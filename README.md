# マーケティング・ボトルネック診断 MVP

このリポジトリは、講座・コンサル・コーチ・オンラインビジネス事業者向けの「マーケティングのボトルネック診断」MVPです。

## 1. アプリ全体コンセプト
- **迷わない、止まらない、気づきがある診断体験**を最優先。
- 1画面1〜3問、進捗バー、やさしい説明文、親しみあるUIで離脱を抑制。
- 結果は「4タイプ + 8カテゴリスコア + 実行アクション」で、次の一歩が明確になる設計。

## 2. 主要機能一覧
- 事前入力（名前、メール、サービス内容、業種、提供形態、集客方法、任意売上ステージ）
- 8カテゴリ×各3問（合計24問）の5段階診断
- セクション説明 + ページ分割表示
- スコア計算（合計 / カテゴリ）
- 4タイプ判定（合計点 + 弱点カテゴリの総合判定）
- 結果画面（レーダー、棒グラフ、強み/ボトルネック、AI活用、次アクション）
- バックエンド保存（診断ID・回答・判定・コメント・日時）
- 管理者API（一覧・検索・絞り込み・CSV出力）

## 5. 質問項目一覧（カテゴリ別）
各カテゴリ3問、5段階評価（1〜5）。

1) 誰に届けるか
- どんな人に届けたいかを、ひとことで説明できますか？
- 理想のお客様の悩みを、具体的に3つ言えますか？
- お客様が「今すぐ解決したい」と感じる課題を把握していますか？

2) どんな変化を届けるか
- あなたのサービスで得られる変化を、わかりやすく伝えられますか？
- 受講・利用前後の違いを、具体例で話せますか？
- 似たサービスとの違いを、やさしい言葉で説明できますか？

3) 発信・集客
- 発信するテーマが毎回ぶれずに統一されていますか？
- 見込み客が見つけやすい場所（SNS/検索/紹介導線）がありますか？
- 毎週の発信や集客行動を、無理なく継続できていますか？

4) 信頼づくり
- お客様の声や実績を、見える形で紹介できていますか？
- 自己紹介・想い・実績が、初めての人にも伝わりますか？
- 発信内容に一貫性があり「この人なら安心」と感じてもらえていますか？

5) 体験の場（セミナー・相談・フロント）
- 初回体験（説明会/相談）に自然につながる導線がありますか？
- 体験の場で、相手の悩みを丁寧に整理できていますか？
- 体験の満足度を上げる工夫（資料・進行・フォロー）がありますか？

6) お申し込み・セールス
- 価格・内容・期間を、迷わず伝えられますか？
- お申し込み方法がシンプルで、途中で迷わない設計ですか？
- 検討中の方へのフォロー（質問対応・再案内）ができていますか？

7) 提供後の成果・継続・紹介
- 提供後に成果を確認する仕組み（面談/アンケート）がありますか？
- 継続提案や次のステップを、自然に案内できていますか？
- 紹介が生まれる工夫（紹介しやすい導線・依頼）ができていますか？

8) サービス内容の明確さ
- サービスの範囲（何をする/しない）が明確ですか？
- 料金に含まれる内容を、誤解なく伝えられますか？
- お客様が比較しやすい形で、プランを整理できていますか？

## 6. 診断ロジック
- 各回答は1〜5点。
- カテゴリスコア = （カテゴリ内合計 / 15）×100
- 合計スコア = 全24問合計（24〜120）
- 正規化合計 = （合計 / 120）×100

## 7. タイプ判定ロジック
- 弱点カテゴリ定義: カテゴリスコア60未満
- タイプ判定（合計 + 弱点数 + 分布）
  - 迷子タイプ: 正規化合計 < 45 または弱点4カテゴリ以上
  - がんばりすぎタイプ: 正規化合計45以上かつ「発信・集客」>=70 かつ「体験の場」「お申し込み」いずれか<55
  - 惜しいタイプ: 正規化合計60以上かつ弱点1〜2カテゴリ
  - 自然に売れるタイプ: 正規化合計75以上かつ全カテゴリ60以上
- 競合時は優先順位: 自然に売れる > がんばりすぎ > 惜しい > 迷子

## 8. 結果画面の表示項目
- 合計スコア（/120）
- 8カテゴリスコア
- 4タイプ結果
- 強み上位2カテゴリ / ボトルネック下位2カテゴリ
- タイプ別のやさしいまとめ文
- 次のアクション3つ
- AI活用アドバイス
- レーダーチャート + 棒グラフ

## 9. AI活用アドバイスの設計
タイプ別に「どのAIを / 何に / どう使うか / なぜ合うか」を表示。

- 迷子タイプ
  - ChatGPT: ターゲット整理と発信案の下書き
  - Gemini: 競合・市場の比較調査
  - NotebookLM: 自分の資料・メモ整理
  - Genspark: 施策アイデア探索
- がんばりすぎタイプ
  - ChatGPT: セールス導線改善の会話シナリオ
  - Gemini: 導線比較と改善示唆
  - NotebookLM: 面談ログから共通課題抽出
  - Genspark: 提案フォーマット生成
- 惜しいタイプ
  - ChatGPT: 弱点カテゴリの改善タスク分解
  - Gemini: 最新トレンド参考案
  - NotebookLM: 事例ナレッジ化
  - Genspark: LP/案内文の比較案
- 自然に売れるタイプ
  - ChatGPT: 標準化・仕組み化ドキュメント
  - Gemini: 新規チャネル探索
  - NotebookLM: 成功要因の再現パターン化
  - Genspark: 拡張オファー案作成

## 10. DB設計
### `diagnosis_sessions`
- id (uuid, PK)
- created_at (datetime)
- name
- email
- service_description
- industry_category
- delivery_format
- customer_acquisition_channels (json)
- revenue_stage (nullable)
- total_score
- normalized_score
- type_result
- result_comment
- strengths (json)
- bottlenecks (json)

### `diagnosis_answers`
- id (uuid, PK)
- session_id (FK)
- category_key
- question_key
- answer_value (1-5)

## 11. API設計
- `POST /api/diagnosis` 診断保存
- `GET /api/diagnosis` 一覧取得（filter: date_from/date_to/industry/type/score_min/score_max/delivery）
- `GET /api/diagnosis/:id` 詳細
- `GET /api/diagnosis/export.csv` CSV出力

## 12. 管理画面設計
- 検索条件: 日付、業種、タイプ、スコア帯、提供形態
- 一覧項目: 日時、名前、業種、タイプ、合計点、主ボトルネック
- 詳細: 全回答、カテゴリ別スコア、コメント
- CSVエクスポート

## 13. UIデザイン方針
- 明るく信頼感ある色（ブルー/パープル/ミント）
- 日本語可読性重視（Noto Sans JP）
- カードUI + アイコン + 進捗バー
- スマホファースト（1カラム、タップ領域44px以上）
- ゲーム感（進捗演出、セクション完了メッセージ）

## 14. 推奨技術スタック
- フロントエンド: Vanilla JS + Tailwind CDN + Chart.js
- バックエンド: Node.js + Express
- DB: MVPはインメモリ（将来: PostgreSQL）
- 認証: 管理画面のみ簡易トークン（将来: Auth0 / Clerk）
- ホスティング: Vercel (FE) + Render/Fly.io (BE)

## 15. MVP開発ステップ
1. 質問・ロジック確定
2. フロント（入力→回答→結果）
3. グラフ表示
4. API保存連携
5. 管理一覧/フィルタ
6. CSV出力
7. 計測・改善

## 16. 実装コードのひな形
- `index.html`: MVP UI + 診断ロジック + 結果可視化
- `backend/server.js`: 保存/検索/CSV API
- `backend/package.json`: 起動設定

起動例:
```bash
cd backend
npm install
npm run dev
```

フロントは `index.html` をブラウザで開いて確認できます。
